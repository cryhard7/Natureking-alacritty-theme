# Natureking-alacritty-theme
A warm , cozy , hint-greenish , clean , sexy , beautiful etc. colorscheme for alacritty!


##how to apply###

1.if you dont already have a config folder for alacritty create one by the command
```mkdir -p ~/.config/alacritty```

2. if you dont have a alacritty config file make one by

```touch ~/.config/alacritty/alacritty.toml```

3. create a themes folder for your themes

```mkdir -p ~/.config/alacritty/themes```

4. In config file

```
[general]
import = [
    "~/.config/alacritty/themes/themes/natureking.toml"
]
```




5.save to see changes
